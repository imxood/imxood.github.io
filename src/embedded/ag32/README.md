## 说明

- 本目录收录 `AG32` 平台相关的开发环境和资料入口记录.
- 当前重点是 `AG32VF407` 这类带 `MCU + FPGA` 特性的国产平台上手资料.

## 建议阅读路径

1. 先看 `AG32VF407 开发环境`, 了解官方资料入口和软件来源.
2. 再根据具体芯片型号确认工具链, 驱动和示例工程版本.
3. 真正开始开发前, 先跑通官方示例, 再进入联合编程或外设验证.
