# 编程总览

## 说明

- 本目录收录通用编程语言, 框架, 后端, 脚本语言与机器人相关笔记.
- 前端知识已优先收敛到 [前端总览](../frontend/README.md), 历史 Web 示例工程归档在 [program/web](./web/README.md).
- 若只是查语言或工具链知识, 优先从本页进入.

## 主要方向

- [Rust](./rust/rust.md)
- [Python 总览](./python/README.md)
- [Dart 与 Flutter 总览](./dart/README.md)
- [C# 总览](./c%23/README.md)
- [C 与 C++ 总览](./c_c++/README.md)
- [Java 总览](./java/README.md)
- [机器人技术总览](./robot/robot.md)
- [ROS2](./robot/ros2.md)

## 高风险任务入口

- 系统编程, 绑定和工具链问题优先看 `Rust` 与 `C/C++`.
- 脚本自动化, 远程运维和快速原型优先看 `Python`.
- 跨端 GUI 和移动端实验优先看 `Dart 与 Flutter`.
- 托管代码与原生库互调优先看 `C# 总览`.
- 机器人中间件与设备协同优先看 `ROS2` 和 `机器人技术总览`.

## 目录边界

- `frontend/` 主要放前端框架, Web 构建和浏览器相关知识.
- `program/` 更偏语言本身, 工具链, 原生开发和跨语言交互.
- `program/web/` 当前主要作为历史示例工程归档, 不再承担核心知识导航职责.
