# Python 工具

## 说明

- 本页汇总 Python 开发中更偏“工具链”和“辅助库”的记录.
- 环境管理优先看 [Conda](./conda.md) 和 [pyenv 使用说明](./pyenv使用说明.md).

## 当前主题

- `psutil`: 用于查看进程, CPU, 内存, 网络等系统信息.
- [Paramiko](./paramiko.md): Python 下常用 SSH 客户端库.
- [Dramatiq](./dramatiq/Readme.md): 偏任务队列与后台任务处理.
- [PySide2 笔记](./pyside2/使用pyside2.md): 偏 GUI 工具链.

## 使用建议

- 先区分当前问题是“环境管理”, “系统交互”, “网络访问” 还是 “GUI”.
- 同一类工具尽量沉淀到专题页, 本页主要保留导航作用.
