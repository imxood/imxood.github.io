# test_usb 实验目录说明

## 说明

- 本目录保存早期 `USB` 方向的最小实验代码和辅助文件.
- 当前更适合作为历史验证目录, 不承担主知识导航职责.
- 如果目标是系统化理解 `libusb` 或 `rusb`, 应优先查看 [rusb](../library_usage/rusb.md).

## 当前文件

- `Cargo.toml`: Rust 侧实验工程配置.
- `src/`: Rust 实验源码.
- `test.c`: 早期辅助验证代码.

## 当前治理结论

- 本轮已为目录补齐最小 `README.md` 入口.
- 当前目录已列为第一批低优先级迁出候选.
- 后续若只剩实验快照价值, 可评估迁入更统一的样例归档区或迁出主知识树.

## 使用建议

- 需要回看早期 USB 验证过程时, 可以从本目录开始.
- 需要新的 USB 开发结论时, 应优先把可复用经验回收到正式知识页.
- 若准备实际接入设备, 先验证驱动, 架构和运行库环境是否正确.
