# JavaScript 零散脚本归档

- 本目录主要保存历史 `JavaScript` 工具脚本, 参考图片和文本资料.
- 这类内容更适合作为素材归档, 不再作为主知识入口.
- 如果目标是系统化前端知识, 应优先回到 [前端总览](../../../frontend/README.md) 和相关正式专题页.

- 其余图片与文本文件主要作为旧资料留存.

- 需要回看老项目里某段工具函数时, 可以在这里按文件名检索.

- 若只是为了学习某个前端主题, 不建议直接从本目录开始.
