# Umi React 示例项目

## 说明

- 本目录是一个基于 `Umi 2` 的历史 React 示例工程.
- 更适合用来回看旧版脚手架结构, 不建议直接作为新项目模板.

## 当前特征

- 使用 `umi dev` / `umi build`.
- 目录中包含 `mock/` 与 `src/`.
- React 版本较旧, 依赖也偏历史版本.
- 更适合回看老项目的工程组织方式, 不适合直接复制到新项目.

## 常用命令

```sh
npm install
npm start
npm run build
npm test
```

## 适用场景

- 回看 `Umi 2` 时代的项目结构.
- 对照现代 React 脚手架理解历史迁移成本.
- 快速验证旧项目在当前环境下还能否运行.

## 使用建议

- 若只是查 React 知识点, 优先返回主文档.
- 若只是比较脚手架结构, 无需深挖业务代码也能获得大部分信息.
- 若真的需要运行, 先确认 Node 版本与旧依赖是否兼容.
