# React 单文件示例

## 说明

- 本目录保存一个非常轻量的 `HTML + React` 试验页.
- 当前主要文件是 `test.html`, 更适合作为最小实验归档而不是正式工程模板.

## 适用场景

- 快速验证 `React` 在纯 HTML 页面中的最小挂载方式.
- 对照理解“直接引入脚本”与“脚手架工程”之间的差异.
- 临时验证小交互, 而不想先搭完整工程时使用.

## 使用方式

- 如果页面依赖 CDN 资源, 直接用浏览器打开即可快速查看.
- 若涉及模块或跨域限制, 可通过本地静态服务器打开.
- 若后续逻辑持续增长, 建议迁移到 `Vite` 或其他现代脚手架工程中.

## 归档说明

- 这类目录更适合作为旧实验归档, 不再作为主知识入口.
- 若只是查 React 知识点, 请优先回到 [React 示例目录](../README.md) 或前端主文档.
