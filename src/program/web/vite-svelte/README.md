# Vite + Svelte 示例归档

## 说明

- 本目录是一个早期 `Vite` + `Svelte` 示例工程, 更适合回看旧版脚手架结构和基础命令.
- 正式知识文档请优先查看 [Svelte](../../../frontend/svelte.md) 与 [Vite](../../../frontend/vite.md).
- 当前目录承担的是历史样例归档职责, 不是新的默认模板入口.

## 适用场景

- 回顾早期 `Vite + Svelte` 工程目录组织方式.
- 快速验证旧项目依赖是否还能启动.
- 作为历史样例对照新模板的脚手架差异.

## 当前特征

- 使用 `svite` 作为开发和构建脚本.
- 更接近早期社区模板, 不建议作为新的默认模板.
- 目录中主要保留样例代码和最小运行结构.

## 当前治理结论

- 当前目录已列为第一批低优先级迁出候选.
- 本轮继续保留说明页和最小运行上下文, 方便回看历史结构.
- 若后续确认只剩脚手架快照价值, 可整体迁出主知识树.

## 常用命令

```sh
yarn
yarn dev
yarn build
```

## 使用建议

- 需要查知识点时, 优先返回主文档.
- 需要验证旧版工具链行为时, 再进入本目录执行命令.
- 若准备新建项目, 建议直接选择更新的官方模板或当前主流脚手架.
