# Vue 示例目录

## 说明

- 本目录保存历史 `Vue` 示例工程与旧脚手架项目, 主要作为归档和回溯入口.
- 正式知识文档请优先查看 [前端 Vue 笔记](../../../frontend/vue/vue.md).
- 当前样例数量不多, 但足够承担“旧工程结构对照”用途.

## 当前示例

- [Vue 单文件示例](./demo/README.md)
- [Vue 示例项目说明](./vue-app/README.md)

## 阅读路径

1. 查 Vue 知识点时, 先看主文档.
2. 需要看最小实验页面时, 进入 `demo`.
3. 需要回看 `vue-cli` 旧项目结构时, 再进入 `vue-app`.

## 归档特征

- 当前目录主要覆盖“单文件实验页”和“旧版脚手架项目”两类历史资料.
- 更适合用于比对旧工程结构, 不建议直接作为新的项目模板来源.
- 如果后续某个子目录只剩命令记录价值, 可继续压缩成更轻的说明页.

## 使用建议

- 若只是查阅 Vue 知识点, 优先看主文档.
- 若需要运行旧版脚手架工程, 再进入对应目录执行命令.
- 做迁移时优先抽取路由, 构建和目录结构思路, 不要机械复用老依赖版本.
