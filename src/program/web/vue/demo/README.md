# Vue 单文件示例

## 说明

- 本目录保存几个早期的 Vue 单文件实验页面.
- 当前主要包括基础示例, 路由示例和 Vuex 示例, 更适合作为最小实验归档.

## 当前文件

- `simple_base.html`
- `simple_router.html`
- `simple_vuex.html`

## 适用场景

- 快速回看 Vue 基础能力在单文件 HTML 中的最小写法.
- 用于教学, 临时验证或脱离脚手架的简单实验.
- 对照理解从“直接引入脚本”到“脚手架工程”的演进差异.

## 使用方式

- 适合直接通过浏览器或本地静态服务器打开查看.
- 如果只是查 Vue 知识点, 更建议优先查看主文档.
- 若要迁移到现代工程, 建议把示例逻辑拆到组件和构建工具链中重新组织.
