# CMake 总览

## 说明

- 本目录保存 `CMake` 常用语法, 调试技巧和若干最小示例文件.
- 适合处理 `CMakeLists.txt`, 工具链文件, 自定义构建脚本和变量排查问题.
- 当前目录同时包含正式笔记和配套样例, 因此需要由总览页承接结构.

## 当前内容

- [CMake 笔记](./cmake笔记.md)
- `CMakeLists.txt`: 最小顶层工程文件.
- `test_build.cmake`, `test_cmake.cmake`, `test_toolchain.cmake`: 用于回看语法和工具链测试方式.
- `test_build.c`: 配套最小源文件.

## 阅读路径

1. 先看 [CMake 笔记](./cmake笔记.md), 理解常用命令, 变量和属性查询方式.
2. 再按需回看 `test_*.cmake` 文件, 对照实际写法理解脚本行为.
3. 若问题已经进入平台工具链或第三方库集成, 再结合 `vcpkg`, `Boost`, `编译工具` 等页面继续查找.

## 适用场景

- 快速回查 `cmake -B build`, `cmake --build` 等常用命令.
- 排查 `toolchain` 文件, `find_package`, 目标属性和变量展开问题.
- 给历史工程补最小可运行的 `CMake` 示例.

## 使用建议

- 正式知识结论优先沉淀在 `cmake笔记.md`, 测试脚本只承担示例辅助职责.
- 若某个测试脚本演变为稳定专题, 再单独升级为正式文档.
- 本目录适合作为工具链知识入口, 不建议把零散测试文件直接挂到主导航.
