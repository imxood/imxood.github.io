# LaTeX 笔记

## 说明

- 本页记录常见数学公式输入速记, 适合写技术文档, 论文和工程说明时快速查找.
- 默认以行内公式为主, 复杂公式可再扩展到独立公式环境.

## 行内公式

- 使用 `$...$` 包裹行内公式.
- 示例: `$E = mc^2$`, `$f(x) = x^2$`.

## 下标与上标

- 单个字符下标: `U$_Z$`
- 多字符下标: `U_{Z,min}`
- 上标: `V_{out}^{max}`
- 上下标同时使用时, 建议优先加 `{}` 保持结构清晰.

## 常见符号

- 变化量: `$\Delta U$`
- 乘号: `$a \times b$`
- 正负号: `$\pm$`
- 小于等于: `$\leq$`
- 约等于: `$\approx$`

## 常见结构

- 分数: `$\frac{a}{b}$`
- 根号: `$\sqrt{x}$`
- 自动伸缩括号: `$\left( \frac{a+b}{c} \right)$`
- 单位或说明文字建议放入 `\mathrm{}` 或公式外普通文本中.

## 使用建议

- 多字符上下标, 分数分子分母和复杂表达式尽量都加 `{}`.
- 文档里若公式较多, 建议统一符号命名, 避免同一变量在不同段落含义漂移.
