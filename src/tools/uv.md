# uv

## uv git

https://github.com/astral-sh/uv

## 使用代理

设置 HTTP_PROXY HTTPS_PROXY 环境变量

## 安装 python

uv python install 3.13

## 查询 python 列表

uv python list

## 默认 Python 设置为 3.13

uv python pin 3.13

## 使用默认 python 运行

uv run python --version

## 卸载 python

uv python uninstall 3.13

## uv 可用的 python

uv python find

## 虚拟环境管理

### 创建

uv venv --python 3.13

### 激活

.\.venv\Scripts\activate
